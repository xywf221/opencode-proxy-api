feat: 企业级反代理升级 - 会话亲和性与健康管理

## 核心改进

### 1. 会话亲和性代理选择
- 使用 FNV-1a 哈希将会话 ID 映射到固定代理
- 支持多种会话标识提取方式：
  * HTTP headers (x-session-id, conversation-id)
  * JSON metadata (session_id, conversation_id)
  * OpenAI user 字段
  * 首条消息内容哈希
- 单代理自动池化，复用健康管理逻辑
- **效果**: 彻底解决"请求几次被标记"问题

### 2. 请求特征多样化
- 新增动态 headers:
  * x-opencode-session: 稳定会话标识
  * x-opencode-request: 每次唯一 UUID
  * x-opencode-project: 随机项目名
- 伪装官方客户端:
  * User-Agent: opencode/1.4.3
  * Referer: https://opencode.ai/
  * X-Title: opencode
- **效果**: 模拟真实客户端行为，增加请求多样性

### 3. 代理健康度管理
- 失败追踪与指数退避 (15s → 30s → 60s → 120s)
- 区分网络错误 vs 业务错误
- 自动故障隔离与恢复
- **效果**: 死代理自动排除，降低失败率

### 4. 智能重试策略
- Retry-After 解析 (支持秒数和 HTTP 日期)
- 429 自动轮换代理
- 指数退避与 Retry-After 融合
- **效果**: 遵守上游限流规则

### 5. 安全改进
- 代理 URL 自动脱敏 (socks5://***:***@host:port)
- 日志永不泄漏明文密码
- **效果**: 生产环境安全合规

### 6. IPv6 兼容性
- 推荐使用 socks5h:// 避免本地 DNS IPv6 问题
- 文档详细说明最佳实践
